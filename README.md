## 📌 About

<p>
This repository is my <b>hands-on project portfolio</b> — everything I build gets pushed here, from small Python scripts to fully deployed Machine Learning, Deep Learning and NLP apps.
</p>

<p>
Unlike a tutorial-follow-along, every project here started from a real dataset or problem and was taken through the full pipeline: <b>data cleaning → EDA → modeling → evaluation → deployment</b>.
</p>

> 🔄 **This repo is a work in progress.** New projects are added as I build them — check back often.

## ⚡ Quick Start

```bash
git clone https://github.com/Rohit-coder-py/My_Projects.git
cd "My_Projects/Machine Learning Projects/<project-name>"
pip install -r requirements.txt
streamlit run app.py
```

<sub>Project folders with an <code>app.py</code> and <code>requirements.txt</code> run the same way. Deep Learning projects live under <code>Deep Learning Projects/&lt;ANN | CNN | RNN&gt; Projects/&lt;project-name&gt;</code>.</sub>
